> **Status:** `PHASE 9.2 COMPLETE` · **Type:** Final Year Project · **Scale:** 111 Hospitals × 24 Districts × 6 RBAC Roles × 3 AI Agents · **Tests:** 64/64

The most technically ambitious project I've built. A **state-wide healthcare emergency operations platform** connecting **111 real government hospitals across all 24 districts of Jharkhand** — with ML-driven triage scoring, Dijkstra shortest-path ambulance routing, autonomous AI agents managing ₹12.80 Cr budgets, a full 108 Ambulance Tactical Command System with 1-click bed pre-booking, **zero-email RFC 6238 TOTP 2FA**, **BIP-39 mnemonic account recovery**, **clinical shift sessions with PIN lock**, and **dual-control staff onboarding with official `JH-STF-XXXX` credentials**.

```
ML Engine:      Logistic Regression severity scorer (4 Kaggle datasets benchmarked)
                Score = Sigmoid(W·X + b) × 100
                98.88% cross-dataset transfer recall
                Risk Tiers: Critical(≥75) · Urgent(50-74) · Moderate(25-49) · Low(<25)

Algorithms:     Dijkstra shortest-path inter-hospital referrals
                Hungarian 3-constraint clinical bed matcher (Bed ∧ Equipment ∧ Specialist)
                Priority Heap with starvation prevention: E = S + λ·W

108 Dispatch:   4-Stage Golden Hour Pipeline
                Incident Intake → Multi-Criteria Hospital Scoring → 1-Click Bed Pre-Booking
                → In-Flight Fleet Telemetry with Live ETA Countdown

AI Agents:      Supply Demand Agent (24/7 autonomous telemetry)
                Financial Cost Recovery Agent (₹12.80 Cr budget · +₹1.46 Cr surplus)
                Dijkstra Regional Overflow Routing Agent

Auth & 2FA:     Zero-email offline RFC 6238 TOTP (Google Authenticator / YubiKey)
                12-word BIP-39 mnemonic recovery · 8 single-use backup codes
                8h/12h clinical shift sessions · 4-digit PIN quick-lock
                Dual-control admin verification queue · JH-STF-XXXX Staff IDs

Security:       22-vector audit · CORS lockdown · @PreAuthorize RBAC
                HttpOnly SameSite JWT cookies · 15-min refresh token rotation
                CSRF guard · Brute-force lockout (5 attempts / 15 min)
                Multi-tenant IDOR prevention · Clinical vitals boundary sanitization
                Atomic pessimistic-lock discharge · Non-root Docker container
                Trusted proxy X-Forwarded-For validation · Structured audit logging

Data Scale:     111 real Jharkhand hospitals (RIMS, MGM, Sadar, SDH, CHC)
                24 districts · 79+ road network edges · GIS coordinates
                12 operational dashboard views · 6 RBAC user roles

SEO & PWA:      Schema.org JSON-LD · OpenGraph · Twitter Cards · Sitemap · Robots
                Web App Manifest · Font display:swap · Preconnect hints

Testing:        64/64 backend test suites — 100% passing
                5 ML algorithms × 4 datasets benchmarked
                Full JPA persistence + REST API integration tests
```
